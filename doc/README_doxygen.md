\section intro_sec Introduction

This is the developer documentation of the reference client for Universal Standard Franc (USFranc, ticker: USFF),
which enables fast, secure peer-to-peer payments to anyone, anywhere in the world. USFranc uses peer-to-peer technology to operate
with no central authority: managing transactions and validating blocks are carried out collectively by the network.

The software is an open source project, released under the MIT license.

See https://usfranc.com/ for further information about the project.
